# 全功能检视（逐模组盘点 → 一个一个详查）

**目标**：让人能「正常且正确」地用每个功能。逐模组检查这 4 件事——
1. **入口**：进得来吗？位置合理、固定、不重复吗？该看到的角色看得到、不该看到的看不到吗？
2. **操作 / 跳转**：点下去顺不顺？跳转对不对、回得来吗？有没有断头路？
3. **字段**：每个栏位有用吗？有没有多余的、该有却缺的、填了没意义的？
4. **模组连动**：这个功能改的数据，会不会影响别的模组？别的模组的状态会不会反过来影响它？（例：团单↔客户订单↔商品库↔数据中心 的数据流）

**检视状态**：未开始 / 进行中 / 完成。「主要发现」在详查后填写。
