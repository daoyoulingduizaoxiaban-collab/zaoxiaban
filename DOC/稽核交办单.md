- [ ] **C1 🔴 列表硬上限 100 笔、无分页，且「先取 100 才过滤」**
      `cloudfunctions/businessData/lib/core.js:361`
      ```js
      const getAllActive = async (name) => {
        const r = await getCollection(name).limit(100).get();
        return (r.data || []).filter(i => !i.deletedAt).map(toId);
      };
      ```
      - 取回 100 笔**之后**才滤 `deletedAt` 与权限 → 软删累积后可见笔数低于 100，且**静默**、不报错

      **要求**：团主可代客户下单，**不受收单截止限制**，且**必须记录是帮谁下的**（要看得出是代下单／哪个团主代的／帮的客户是谁）。
