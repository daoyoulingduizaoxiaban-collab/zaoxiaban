# QA BUG 單 - 待修問題清單

## 強制規則

本文件只保留 `修正問題`。開發需求、MVP gate、產品完成度與 backlog 必須寫在 `MVP_COMPLETION_CHECKLIST.md`，不得混在本 BUG 單。

本文件不是歷史紀錄本。項目不能因為舊文字、舊通過紀錄或代理過去自稱測過就關閉；每次驗收都必須重新從目前版本完整操作一次。

每一列都必須能被單獨修正、單獨驗收、單獨關閉。不能把多頁、多角色、多流程或多個驗收點塞在同一列。

不得保留 `通過` 項目。修好並驗收通過後，從本清單移除；若仍有衍生問題，另開一列具體問題。

不得新增 Priority / 優先級、下一步、摘要、補充清單、歷史清單或第二張表。

不得保留籠統項目。若一列無法說清楚要修正哪個問題，必須拆小、改寫或移除；若它其實是開發需求，必須移到 `MVP_COMPLETION_CHECKLIST.md`。

Status 只能寫 `不通過`。本清單不存放已通過項目。
